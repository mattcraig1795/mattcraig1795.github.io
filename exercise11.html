JavaScript If/Else Statements

JavaScript "if" Statement

JavaScript uses if and else statements to make decisions. You can use the if statement to execute a block of code when a condition is true

If the condition is true, JavaScript runs the code inside the brackets. If it is false, JavaScript skips that code.

Note: JavaScript is case-sensitive, meaning that the if statement must always be written in lowercase. Writing "If" or "IF" will cause a JavaScript error.

JavaScript "else" statement

The else statement tells JavaScript what to do when the if condition is false. This allows us to have two different outcomes depending on the condition.

Example of If/Else

Example:

let hp = 0;

if (hp > 0) {

message = "Your character is still standing!";

} else {

message = "Your character is unconscious!";

}

Result:

Your character is unconscious!

Why Are If/Else Statements Useful?

If/else statements are useful because they allow websites to respond differently depending on certain conditions. For example, they can check someone's age, compare numbers, or determine whether a user entered the correct information.
